# Bundled symbolic icons

The `mchose-*-symbolic.svg` files are standard GNOME symbolic icons, copied
from the Adwaita icon theme and renamed so the application always has them
available regardless of the user's icon theme.

- Source: Adwaita icon theme, https://gitlab.gnome.org/GNOME/adwaita-icon-theme

`top.ddmt.mchosehub.svg` is this project's own application icon (GPL-3.0-or-later).
